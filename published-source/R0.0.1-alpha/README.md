# Опубликованные исходники xdytube v0.0.1-alpha

Архив получен командой `git archive` из `d3ab58329c29c61836217f3ec4b350d2bba2fa62`, на который указывает тег `v0.0.1-alpha`. В архив вошли 135 файлов, отслеживаемых Git на момент сборки. [Заметка о выпуске](../../release-notes/R0.0.1-alpha.md)

За пределами архива остались `.git`, локальные варианты дизайна, файлы кандидата, временный тестовый профиль, пользовательская SQLite, настройки, сессии браузера и другие файлы авторизации. Текстовые файлы проверены на известные форматы секретов и абсолютные пути домашних каталогов.
