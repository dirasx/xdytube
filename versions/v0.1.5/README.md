# Working version v0.1.5 — macOS player controls

Based on [v0.1.4](../v0.1.4/README.md). In fullscreen, the cursor hides with the controls during playback and reappears when the mouse moves. The player exposes playback state and accepts system media commands; previous and next navigation is available within the queue.

Tasks: XDT-002, XDT-003. A later report found that controls did not reappear after moving the mouse; that issue remains open.
