# Рабочая версия v0.1.5 — управление плеером на Mac

Основа — [v0.1.4](../v0.1.4/README.md). В полноэкранном режиме курсор скрывается вместе с панелью во время воспроизведения и появляется при движении мыши. Плеер передаёт состояние воспроизведения в macOS и принимает системные команды. Переключение на предыдущий или следующий ролик доступно в пределах очереди.

Задачи: XDT-002, XDT-003.
