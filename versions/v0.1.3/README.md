# Рабочая задача v0.1.3 — macOS Apple Silicon

Основа — [`v0.1.2`](../v0.1.2/README.md). Убраны собственные ветки Windows и Linux, платформенные ресурсы, установщики и локальный Windows-патч GPUI. Обычный CI проверяет только сборку и тесты macOS arm64. Транзитивная зависимость GPUI для Windows остаётся в lockfile и не собирается для Apple Silicon.

Кандидат теперь собирается явным запуском workflow `macOS release candidate`. На выходе ad hoc-подписанный ZIP и `SHA256SUMS.txt`. Публикация остаётся отдельным шагом. Приложение открывает приватную страницу загрузок GitHub для ручного обновления.

Команда `cargo check --release --locked` прошла. Проверены временный ZIP, SHA-256, arm64, подпись после распаковки, запуск с чистым профилем и передача повторного запуска первому экземпляру. На этом этапе оставалось проверить минимальную поддерживаемую версию macOS и открытие ссылки из браузера при холодном запуске.
