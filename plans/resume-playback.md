# Возобновление частично просмотренного видео

**Статус** — в работе, этап диагностики. Причина пока не установлена. Ошибка замечена в `v0.0.1-alpha` на macOS.

На карточке ролика длительностью `1:28:01` красная полоса занимает примерно 15% ширины. После открытия плеер показывает `0:00 / 1:28:00`. При включённой настройке `Resume where you left off` частично просмотренный ролик должен открываться с сохранённой позиции.

## Диагностика и исправление

- [ ] Воспроизвести сбой на отдельном профиле с включённым возобновлением. Использовать тестовое видео с известной позицией, например 120 секунд из 600. Проверить повторное открытие из карточки после выхода с видео и после перезапуска приложения.
- [ ] Сравнить три значения для одного видео. Карточка читает кэш `Watched`, контроллер при открытии заново читает прогресс из SQLite, затем передаёт выбранную позицию в libmpv как `start`. Определить, на каком шаге позиция теряется. [Карточки](../src/ui/cards.rs) · [Хранилище](../src/store.rs) · [Контроллер](../src/player/controller.rs)
- [ ] Воспроизвести найденную причину в регрессионном тесте. Исправить участок, теряющий позицию, и подтвердить, что новый тест проходит.

## Критерии готовности

- [ ] При открытии из карточки плеер продолжает с сохранённой позиции для локального просмотра и для позиции, синхронизированной из YouTube. Проверить повторное открытие и перезапуск.
- [ ] Проверить приоритет явного таймкода, запуск с нуля при отключённом возобновлении и существующее правило для роликов, близких к концу.
- [ ] Запустить `cargo test --release --locked` на Apple Silicon. Результат автоматических и ручных проверок зафиксировать в статусе задачи.
