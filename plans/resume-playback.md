# Возобновление частично просмотренного видео

**Статус** — исправление в рабочей версии. Ручная проверка с историей YouTube остаётся открытой. Ошибка замечена в `v0.0.1-alpha` на macOS.

На карточке ролика длительностью `1:28:01` красная полоса занимает примерно 15% ширины. После открытия плеер показывает `0:00 / 1:28:00`. В установленной альфе такое поведение объясняется выключенной настройкой `Resume where you left off`. По решению владельца возобновление стало постоянным, тумблер удалён.

## Диагностика и исправление

- [x] Сверить путь позиции. Карточка читает кэш `Watched`, контроллер при открытии заново читает прогресс из SQLite и передаёт позицию в libmpv как `start`. В отдельной проверке libmpv начал тестовое видео с заданной секунды. [Карточки](../src/ui/cards.rs) · [Хранилище](../src/store.rs) · [Контроллер](../src/player/controller.rs)
- [x] Воспроизвести потерю позиции при закрытии видео до загрузки. До исправления тест показал, что сохранённые `120 / 600` секунд заменялись на `0 / 0`. В рабочей версии плеер сохраняет существующую позицию, пока видео загружается, и сохраняет стартовую позицию при переходе на резервный поток.
- [x] Удалить тумблер и всегда использовать подходящую сохранённую позицию. Настройка из старого профиля больше не управляет возобновлением.

## Критерии готовности

- [ ] При открытии из карточки плеер продолжает с сохранённой позиции для локального просмотра и для позиции, синхронизированной из YouTube. Проверить повторное открытие и перезапуск.
- [x] Подтвердить регрессионными тестами приоритет явного таймкода, пределы сохранённой позиции и сохранение позиции при раннем закрытии и переходе на резервный поток.
- [x] Запустить `cargo test --release --locked` на Apple Silicon. Прошли 40 тестов, 20 пропущены.
