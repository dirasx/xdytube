# План ближайшего выпуска xdytube

Опубликован альфа-релиз [`v0.0.1-alpha`](../release-notes/R0.0.1-alpha.md) на основе [`v0.1.0`](../versions/v0.1.0/README.md). Владелец определит состав следующего выпуска после проверки альфы. Порядок передачи кандидата описан в [WORKFLOW.md](../WORKFLOW.md).

## В работе

- [ ] [Возобновление частично просмотренного видео](resume-playback.md) — в рабочей версии [`v0.2.0`](../versions/v0.2.0/README.md) возобновление включено постоянно. Осталась ручная проверка из карточки и после перезапуска.

## Согласованная очередь разработки

После исправления возобновления берём задачи в этом порядке. Состав следующего релиза определим отдельно.

1. [ ] [Отдельный профиль xdytube и Keychain](backlog.md#отделить-профиль-и-хранить-сессии-в-keychain). Перенести локальные данные с возможностью отката и проверить сохранение доступа после перезапуска.
2. [ ] [Сборка только для macOS на Apple Silicon](backlog.md#оставить-сборку-для-macos-на-apple-silicon). Убрать Windows и Linux из кода и CI, упростить выпуск macOS.
3. [ ] [Цвет надписи xdytube](backlog.md#оформление-приложения). Заменить красный цвет `tube` на фиолетовый оттенок из иконки и проверить обе темы.

## Вошло в v0.0.1-alpha

- [x] Заменить иконку macOS на вариант 4. Иконка обновлена в пакете приложения, внутри xdytube и на главной странице проекта. PNG сравнили с макетом, `.icns` проверили. Коммит `64efde0`.
- [x] После `Settings → General → YouTube watch history → Connect` показывать выбор установленных поддерживаемых браузеров. Запускать браузер после выбора. При закрытии браузера до входа возвращать выбор. При пустом списке показать пояснение и сохранить имеющийся импорт `cookies.txt`. Коммит `1a6b94e`. ## Ручные проверки альфы

- [ ] На Mac с Chrome и Яндекс Браузером убедиться, что `Connect` открывает выбор. Выбрать по очереди Chrome и Яндекс Браузер, проверить открытие нужного окна, отмену и повторную попытку. Использовать чистый профиль xdytube.
- [ ] С тестовым аккаунтом проверить подключение, появление просмотра и его позиции после остановки, возобновление на другом устройстве, сохранение подключения после перезапуска и отключение. Проверить истёкшую сессию отдельно. Полный цикл отправки просмотра пока не подтверждён. [Контекст](../docs/HANDOFF.md)
- [ ] Убедиться, что Finder и Dock показывают иконку установленной альфы, а логотип в приложении соответствует варианту 4.

## На согласование

- [ ] Пояснить в `Settings → General`, что `YouTube account → Sign in` включает функции аккаунта, в том числе Watch Later и чтение истории. `YouTube watch history → Connect` отдельно включает отправку просмотров и позиций. Проверить описания до и после входа. [Настройки](../src/ui/pages/settings.rs)
