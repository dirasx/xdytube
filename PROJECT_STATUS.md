# Статус xdytube

Обновлено 25 ноября 2026 года. xdytube — личный некоммерческий форк Stream Tube Desktop для macOS на Apple Silicon. Репозиторий приватный. Сейчас приложение предназначено для локального использования.

| Рабочая основа выпуска | [`v0.1.0`](versions/v0.1.0/README.md). В альфу вошли иконка macOS по варианту 4 и выбор браузера для подключения истории YouTube. |
| Текущая рабочая версия | [`v0.1.1`](versions/v0.1.1/README.md). Возобновление видео включено постоянно, тумблер удалён. |

| Следующие задачи | По порядку — отдельный профиль и Keychain, сборка только для macOS на Apple Silicon, цвет надписи xdytube. [Очередь разработки](plans/next-release.md#согласованная-очередь-разработки) |
