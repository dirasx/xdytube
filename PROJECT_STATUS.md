# Статус xdytube

Обновлено 25 ноября 2026 года. xdytube — личный некоммерческий форк Stream Tube Desktop для macOS на Apple Silicon. Репозиторий приватный. Сейчас приложение предназначено для локального использования.

| Этап | Состояние |
| --- | --- |
| Последний опубликованный пакет | [Пререлиз `0.7.2-alpha.xdy.1`](https://github.com/dirasx/xdytube/releases/tag/xdytube-0.7.2-alpha.xdy.1), коммит `c811140`, macOS arm64. |
| Рабочая версия | [`v0.1.0`](versions/v0.1.0/README.md) открывает новую нумерацию. В исходниках есть иконка macOS по варианту 4 и выбор браузера для подключения истории YouTube. |
| Проверки | `cargo test --release --locked` на macOS arm64 — 37 прошли, 20 пропущены. Ручное открытие Chrome и Яндекс Браузера через диалог, отмена и повторный выбор остаются в плане проверки. |
| Следующий пункт на согласование | Пояснить в настройках назначение `Sign in` и `Connect`. |
| Ближайший выпуск | Состав согласует владелец. Сборка кандидата и публикация — отдельные шаги по его команде. |
