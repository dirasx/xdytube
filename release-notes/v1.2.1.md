# xdytube v1.2.1 — Release Notes

**Release date:** November 25, 2026

This update improves fullscreen playback controls and playlist management.

## What's New

- **Fullscreen player:** The controls can respond to mouse movement after they have hidden.
- **YouTube playlists:** Remove a specific video from an editable online playlist.

## Installation and Upgrade Notes

Download the DMG, quit xdytube, and drag the new app into Applications to replace the previous version. You can also use the in-app update feature when updating from v1.2. Install libmpv with `brew install mpv` if it is not already installed. The app is ad hoc signed; if macOS blocks the first launch, allow it under Privacy & Security.
