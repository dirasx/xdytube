## Что изменилось

- `Connect` в настройках истории YouTube предлагает выбрать установленный браузер, включая Chrome и Яндекс Браузер.
- Иконка macOS и логотип в приложении обновлены до варианта 4.

## Проверки

- На Apple Silicon 37 тестов прошли, 20 пропущены. Проверены arm64, ad hoc-подпись, целостность ZIP и открытие окна приложения с чистым профилем.
- ZIP и `SHA256SUMS.txt`, скачанные с GitHub после публикации, побайтово совпали с проверенным кандидатом. Контрольная сумма ZIP подтверждена.
- На момент публикации оставались ручные проверки запуска обоих браузеров из интерфейса, синхронизации с реальным аккаунтом и иконки в установленном приложении.

Для воспроизведения требуется Homebrew libmpv (`brew install mpv`). Приложение использует прежний локальный профиль Stream Tube для сохранения настроек и прогресса.
