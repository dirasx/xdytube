## Changes

- `Connect` in YouTube history settings offers a choice of installed browsers, including Chrome and Yandex Browser.
- The macOS icon and in-app logo were updated to variant 4.

## Validation

- On Apple Silicon, 37 tests passed and 20 were ignored. arm64, ad hoc signing, ZIP integrity, and opening the app with a clean profile were checked.
- The ZIP and `SHA256SUMS.txt` downloaded from GitHub matched the verified candidate byte for byte; the ZIP checksum was confirmed.
- At publication, manual checks remained for launching both browsers from the UI, synchronization with a real account, and the installed app icon.

Homebrew libmpv (`brew install mpv`) is required for playback. The app uses the previous local Stream Tube profile to preserve settings and progress.
