# xdytube v1.2 — Release Notes

**Release date:** November 25, 2026

This release establishes the new version numbering for xdytube. It contains the features previously released in R0.2 and updates the release checker to recognize the new version format.

## What's New

- **Versioning:** This release is v1.2 (package version 1.2.0). Future small fixes can use versions such as v1.2.1, while a larger set of improvements may become v1.3.
- **Updates:** The release checker understands the new v-prefixed tags and still recognizes earlier R-prefixed releases.
- **From R0.2:** Watch Later, queue improvements, and in-app update installation remain available.

## Installation and Upgrade Notes

1. Download the DMG, open it, and drag **xdytube** to Applications. Quit the previous app before replacing it.
2. Install libmpv with `brew install mpv` if it is not already installed.
3. The package is ad hoc signed. If macOS blocks the first launch, allow it under Privacy & Security.

Install v1.2 manually when upgrading from R0.2: the older update checker does not recognize the new v-prefixed tag. Profile data is stored separately from the app. After installation, check both YouTube sign-ins and Watch Later.
