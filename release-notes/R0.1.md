# xdytube R0.1

Выпуск для macOS на Apple Silicon опубликован 25 ноября 2026 года в 04:54 МСК. Версия пакета — `0.1.0`. Тег `R0.1` указывает на коммит `3cf62fa7d5b42e297f1f613b81917b64de1de11f`. В выпуск вошли рабочие версии [`v0.1.1`](../versions/v0.1.1/README.md)–[`v0.1.6`](../versions/v0.1.6/README.md). [GitHub Release](https://github.com/dirasx/xdytube/releases/tag/R0.1) · [Снимок исходников](../published-source/R0.1/README.md)

## Что изменилось

- Частично просмотренные видео продолжаются с сохранённой позиции. Таймкод в ссылке имеет приоритет.
- Настройки и локальные данные переносятся в отдельный профиль xdytube. Новые входы в YouTube хранятся в Связке ключей macOS.
- В полноэкранном видео курсор скрывается вместе с элементами управления. Поддерживаются системные команды воспроизведения и переходы по очереди.
- При долгом подключении истории YouTube появляется подсказка о сети. Каждая попытка использует отдельный временный профиль браузера.
- Сборка ориентирована на Apple Silicon. Цвет надписи xdytube соответствует иконке в обеих темах.

## Проверки

- На Apple Silicon прошли 45 тестов, 20 пропущены. Проверены архитектура arm64, целостность ZIP, SHA-256, версия пакета и ad hoc-подпись распакованного приложения.
- На macOS 27.2.1 распакованное приложение открыло окно с пустым временным профилем.
- ZIP и `SHA256SUMS.txt`, скачанные с GitHub после публикации, побайтово совпали с проверенным кандидатом.
- На момент публикации оставались ручные проверки курсора и F7–F9, реальной истории YouTube, обоих входов после обновления и минимальной версии macOS.

Для воспроизведения нужен Homebrew libmpv (`brew install mpv`). После обновления с альфы потребуется заново подключить оба вида входа в YouTube.
