## Changes

- Partially watched videos resume from their saved position. A timestamp in a link takes priority.
- Settings and local data migrate to a separate xdytube profile. New YouTube sign-ins are stored in macOS Keychain.
- In fullscreen, the cursor hides with the controls. System playback and queue navigation commands are supported.
- A network hint appears when connecting YouTube history takes too long. Each attempt uses a separate temporary browser profile.
- Builds target Apple Silicon. The xdytube wordmark matches the icon in both themes.

## Validation

- On Apple Silicon, 45 tests passed and 20 were ignored. arm64, ZIP integrity, SHA-256, package version, and the extracted app's ad hoc signature were checked.
- On macOS 27.2.1, the extracted app opened a window with a clean temporary profile.
- The ZIP and `SHA256SUMS.txt` downloaded from GitHub matched the verified candidate byte for byte.
- At publication, manual checks remained for cursor behavior and F7–F9, real YouTube history, both sign-ins after updating, and the minimum macOS version.

Homebrew libmpv (`brew install mpv`) is required for playback. Both YouTube sign-ins need to be reconnected after updating from the alpha.
