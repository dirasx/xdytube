# xdytube R0.2

Сборка для Mac с Apple Silicon.

## Изменения

- Обновлён Watch Later: добавление и удаление видео работают с подключённой браузерной сессией YouTube. Локальный Watch Later скрыт, а Favorites сохранён.
- Исправлена ширина строк очереди. Из меню видео убран пункт удаления из истории.
- Добавлены проверка новых релизов GitHub и установка обновлений после подтверждения с сохранением предыдущей копии.

## Установка

Установите libmpv командой `brew install mpv`, распакуйте ZIP и переместите `xdytube.app` в «Программы». Пакет подписан ad hoc. Если macOS блокирует первый запуск, откройте его через «Конфиденциальность и безопасность».

После установки проверьте подключение аккаунта и истории, а также добавление и удаление видео в Watch Later. Для обновления с R0.1 потребуется установить этот выпуск вручную: в R0.1 обновления ещё нет.
