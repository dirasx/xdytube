# xdytube R0.2 — заметки о выпуске

**Дата выпуска:** 25 ноября 2026 года

В этом выпуске обновлены Watch Later, очередь видео и механизм обновления приложения. Сборка предназначена для Mac с Apple Silicon.

## Что нового

- **Watch Later:** добавляйте и удаляйте видео в списке YouTube через подключённую браузерную сессию. Локальный список Watch Later скрыт, Favorites сохранён.
- **Очередь и меню:** исправлена ширина строк очереди; из меню видео убран пункт «Remove from history».
- **Обновления:** приложение проверяет новые релизы GitHub и предлагает установить обновление с сохранением предыдущей копии приложения.

## Установка и обновление

1. Скачайте DMG из файлов релиза, откройте его и перетащите **xdytube** в папку «Программы». При обновлении сначала закройте приложение и замените предыдущую копию.
2. Установите libmpv командой `brew install mpv`, если он ещё не установлен.
3. Пакет подписан ad hoc. Если macOS заблокирует первый запуск, откройте приложение через «Конфиденциальность и безопасность».

Для перехода с R0.1 эту версию нужно установить вручную: встроенная установка обновлений появится после перехода на R0.2. Данные профиля хранятся отдельно от приложения. После установки проверьте подключение YouTube и истории, а также работу Watch Later.

**Полный список изменений:** [R0.1 → R0.2](https://github.com/dirasx/xdytube/compare/R0.1...R0.2)
