# xdytube R0.2 — Release Notes

**Release date:** November 25, 2026

This release updates Watch Later, the video queue, and app updates. It is built for Mac with Apple Silicon.

## What's New

- **Watch Later:** Add and remove videos from YouTube Watch Later using the connected browser session. Local Watch Later is hidden; Favorites remains available.
- **Queue and menu:** Fixed queue row width and removed “Remove from history” from the video menu.
- **Updates:** The app checks GitHub for new releases and offers to install an update while keeping a backup of the previous app.

## Installation and Upgrade Notes

1. Download the DMG from the release assets, open it, and drag **xdytube** to Applications. When upgrading, quit the app first and replace the previous copy.
2. Install libmpv with `brew install mpv` if it is not already installed.
3. The package is ad hoc signed. If macOS blocks the first launch, allow it under Privacy & Security.

To upgrade from R0.1, install this release manually: in-app updates become available after installing R0.2. Profile data is stored separately from the app. After installation, check both YouTube sign-ins and Watch Later.
