# xdytube — передача проекта

Состояние на 25 ноября 2026 года. **xdytube** — личный форк [Stream Tube Desktop](https://github.com/Avaneesh-Inamdar/Stream-Tube-Desktop) автора Avaneesh Inamdar. Репозиторий [dirasx/xdytube](https://github.com/dirasx/xdytube) приватный, основная ветка — `main`. Исходная история Git и MIT-лицензия сохранены. Первая версия форка собрана из ветки upstream `community/macos-apple-silicon` на базе `0.7.2-alpha`. Правки вошли в коммит `c811140` и [пререлиз для macOS arm64](https://github.com/dirasx/xdytube/releases/tag/xdytube-0.7.2-alpha.xdy.1).

## История и локальные данные

- **On this device** показывает локальные просмотры. **YouTube history** читает историю аккаунта через обычный вход **YouTube account → Sign in** в приложении. **YouTube watch history → Connect** отдельно подключает отправку просмотров из xdytube в историю YouTube.
- Подключённая сессия сохраняется после перезапуска приложения и Mac. Повторный вход требуется, если YouTube перестал принимать сессию. Яндекс проверен на пустом временном профиле. Успешная запись реального просмотра в аккаунт не подтверждена.
- Safari напрямую не подключён. Для этого проекта не выдавать приложению доступ ко всему хранилищу cookies Safari. Пользователь выбрал вход через уже установленный Яндекс Браузер без расширения и ручного экспорта.
- На macOS xdytube использует прежний каталог `~/Library/Application Support/StreamTube`, чтобы сохранить настройки и прогресс. В нём есть `settings.json`, SQLite и данные входа. При сборке и публикации брать только исходники и пакет приложения. Для изолированного тестового запуска есть `STREAMTUBE_DATA_DIR`.

## Сборка и выпуск

- Первая рабочая версия новой нумерации — `v0.1.0`. Она вошла в [альфа-релиз `v0.0.1-alpha`](../release-notes/R0.0.1-alpha.md). Актуальные задачи и условия выпуска доступны в [статусе проекта](../PROJECT_STATUS.md) и [правилах работы](../WORKFLOW.md).
- Платформа первого релиза — macOS на Apple Silicon. Для воспроизведения нужен Homebrew libmpv (`brew install mpv`). В CI указан Rust `1.100.0`. Сборка и упаковка — `bash packaging/macos/build-app.sh`, тесты — `cargo test --release --locked`. [macOS workflow](../.github/workflows/macos.yml)
- В приватном релизе опубликованы ZIP с `xdytube.app` и `SHA256SUMS.txt`. Пакет подписан ad hoc. Обновления на macOS скачиваются вручную со страницы приватных релизов.
- При первом выпуске проверены архив, подпись, архитектура arm64 и 36 тестов. 20 тестов были пропущены согласно настройкам проекта. Пакет установлен в `/Applications/xdytube.app`. Предыдущая сборка сохранена в ZIP. Первый запуск установленного xdytube вручную не подтверждён.
- Резервные копии держать в ZIP. Распакованные промежуточные `.app` ранее появлялись в Spotlight как дубли.

## Возможные следующие задачи

Twitch и Boosty пока только обсуждались. Для Twitch рассмотрена лента эфиров по подпискам через официальный OAuth Device Code Grant и разрешение чтения подписок. Просмотр сначала можно открывать в браузере. Для Boosty рассмотрена вкладка-ссылка в обычный браузер. Официальный публичный API для чтения личных подписок и закрытых постов не найден. Встроенную веб-вкладку можно исследовать отдельно, включая вход и воспроизведение.
